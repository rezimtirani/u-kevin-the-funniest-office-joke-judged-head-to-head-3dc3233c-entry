One short joke about office life, in a single line: the out-of-office reply that quotes "per my last email", so even the writer's absence turns out to be passive-aggressive.

> I put 'per my last email' in my out-of-office reply. Even my absence is passive-aggressive now.

## How it works

`main.py` (Python 3 standard library only) writes the joke to `$MAKEFUN_OUTPUT_DIR/entry.txt`, checked first against the competition gate: 1 to 200 characters of UTF-8 text, a single line.

```sh
python3 main.py
```
